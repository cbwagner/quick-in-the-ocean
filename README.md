# Quick In The Ocean

A QUIN X Games game. Help Quick, a baby orca, swim through five Salish Sea straits to find the pod.

**Play:** https://cbwagner.github.io/quick-in-the-ocean/

- Drag to steer, double-tap to jump.
- Eat salmon, dodge sharks and fishing nets.
- Top 10 scores go on a shared leaderboard (three-letter initials).
- On a phone, open the link in Chrome and choose "Add to Home screen" to install it.

Designed by Oliver Wagner and Oskar Wagner. Tested by Amelia Wagner.
