QUICK IN THE OCEAN — home-screen app
A QUIN X Games game

What's in this folder
  index.html             the game
  manifest.webmanifest   tells phones the app's name, icon and colours
  sw.js                  lets the game work offline after the first visit
  icons/                 app icons (made from the Quick App Icon design)
  fonts/                 the game's fonts, so nothing loads from the internet

1. Put the folder online (free)
   Phones only offer "install" for a game served from a real https web address.
   Any static host works. Two easy ones:
   - Netlify: make a free account, open "Add new site" > "Deploy manually",
     and drag this whole folder onto the page. You get an https address.
   - GitHub Pages: make a repository, upload these files, then turn on Pages
     in the repository's Settings.
   Upload the folder's contents as they are. Keep index.html at the top level.

2. Install it on an Android phone
   - Open the address in Chrome.
   - Tap the three-dot menu, then "Add to Home screen" (or "Install app").
   - Quick's icon appears on the home screen and opens full screen.
   After the first visit it plays without an internet connection.

3. On an iPhone or iPad
   Open the address in Safari, tap Share, then "Add to Home Screen".

Updating the game later
   Replace the changed files on the host, then open sw.js and change
   VERSION = 'quick-v5' to 'quick-v6' (and so on). Phones pick up the new
   version the next time the game is opened with internet.
